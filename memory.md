# OneMeet --- Project Memory

## Project Identity
- **Project Name**: OneMeet
- **Tagline**: One place. One meeting. One connection.
- **Type**: Real-time Video Conferencing and Collaboration Platform

## Core Constraints
1. **Backend**: Strictly Python Django (DRF, Channels, Redis, PostgreSQL). NO Node.js/Express/Socket.IO.
2. **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3, Fetch API, Canvas API, WebRTC browser APIs.
3. **Real-time**: WebRTC for media; Django Channels / WebSockets for signaling, chat, whiteboard, presence.
