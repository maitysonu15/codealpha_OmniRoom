# OneMeet --- Design Specification

## 1. Design Direction

OneMeet should look like a modern SaaS communication product: clean, minimal, professional, and focused on the meeting experience.

**Design principles:**
- Simple navigation
- High readability
- Strong visual hierarchy
- Meeting controls always easy to access
- Responsive layout
- Accessible buttons and forms
- Consistent spacing and typography
- Avoid unnecessary visual clutter

## 2. Brand

**Name:** OneMeet
**Tagline:** One place. One meeting. One connection.

## 3. Main Screens

### 3.1 Landing Page
Navbar, Hero, Primary CTA: Start Meeting, Secondary CTA: Join Meeting, Feature cards, Security section, Collaboration section, Footer.

### 3.2 Authentication
Login, Register, Logout. Centered cards, clean form fields, validation feedback.

### 3.3 Dashboard
Welcome section, Create Meeting button, Join Meeting field, Recent meetings list, User profile, Logout action.

### 3.4 Meeting Room
Video grid/screen share layout, Meeting header with Meeting ID, Control bar (Mic, Camera, Screen Share, Chat, Files, Whiteboard, Leave), Side panel drawer for Chat, Participants, Files, Whiteboard.

## 4. UI Components
Navbar, Button, Input, Modal, Toast, Avatar, Badge, Video tile, Control button, Sidebar panel, File row, Chat message.

## 5. Color System
- Primary: Indigo/Blue (`#4f46e5`, `#6366f1`)
- Surface / Card: Clean white & dark slate slate-900 background (`#0f172a`, `#1e293b`)
- Accent / Success: Emerald (`#10b981`)
- Error: Rose/Red (`#f43f5e`)
